# 【MTC2】台北捷運C321型
## 【概要】

主に台北捷運の板南線で運用されているC321型を再現したアドオンです。
6両固定編成の組成が可能です。
RTX・Vibrant Visualsに対応しています。

### 収録方向幕

*   Mode1: 頂埔
*   Mode2: 亞東醫院
*   Mode3: 昆陽
*   Mode4: 南港展覽館
*   Mode5: 回送
*   Mode6~8: 空幕

（※ライトの切り替えはカスタムアニメーション側で行います。）

### 列車番号設定方法

当アドオンでは列車番号を任意の三桁の番号に変更可能です。
`scoreboard` コマンドで `mtc072926_1`, `_6` の `mtc_num` の値を変更してください。

**コマンド例:**
```mcfunction
/scoreboard players set @e[type=mtc:mtc072926_1] mtc_num 123
```
（※使用時にはベータAPI機能を有効にしてください。）
